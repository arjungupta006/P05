# IMDB Movie Review Sentiment Analysis

## 1. Project Overview

This project uses Natural Language Processing (NLP) and machine learning
to classify IMDB movie reviews as positive or negative.

The objective is to compare text preprocessing techniques, feature
representations, and classification algorithms to identify a model that
generalizes well to unseen movie reviews.

## 2. Dataset

- **Dataset:** IMDB Dataset of 50K Movie Reviews
- **Source:** Kaggle — IMDB Dataset of 50K Movie Reviews
- **Total reviews:** 50,000
- **Features:** Review text and sentiment label
- **Target classes:** Positive and Negative
- **Task:** Binary text classification

The dataset contains 25,000 positive and 25,000 negative reviews.

The original CSV is stored locally and is not included in this repository.
The processed training and testing files are also excluded from version
control where required by the project guidelines.

## 3. Exploratory Data Analysis

The exploratory analysis examines:

- Dataset dimensions and column types
- Missing values
- Class distribution
- Duplicate reviews
- Review-length distributions
- Examples of positive and negative reviews

The dataset contains 418 duplicate review rows. Identical review texts
were kept in the dataset, but the train-test split was constructed so
that identical reviews do not occur in both sets.

This reduces the risk of data leakage caused by duplicate reviews.

## 4. Data Preprocessing

The preprocessing experiments investigate:

- HTML tag removal
- Lowercasing
- Punctuation removal
- Stop-word removal
- Count-based text representation
- TF-IDF feature representation
- Unigram and bigram features

Preprocessing transformations are implemented inside scikit-learn
pipelines so that vectorization is fitted only on training data during
cross-validation.

### Preprocessing Ablation

| Configuration | Mean CV Accuracy |
|---|---:|
| Raw text | 88.69% |
| HTML removal | 88.73% |
| Lowercasing | 88.73% |
| Punctuation removal | 88.73% |
| Stop-word removal | 88.00% |

Stop-word removal reduced accuracy. Common words can carry useful
sentiment information, particularly negation, so removing them is not
always beneficial for sentiment classification.

### Feature Representation

| Representation | Mean CV Accuracy |
|---|---:|
| CountVectorizer | 88.73% |
| TF-IDF unigrams | 89.35% |
| TF-IDF unigrams and bigrams | 90.12% |

TF-IDF performed better than raw counts. Adding bigrams improved
accuracy further by allowing the model to learn short word combinations.

## 5. Model Comparison

Four classification algorithms were evaluated using cross-validation
and hyperparameter tuning.

| Model | Best Parameters | Mean CV Accuracy |
|---|---|---:|
| Logistic Regression | C = 10 | 91.21% |
| Multinomial Naive Bayes | alpha = 0.1 | 88.81% |
| Linear SVM | C = 1 | 91.34% |
| Random Forest | max_depth = None, n_estimators = 100 | 84.55% |

Linear SVM achieved the highest cross-validation accuracy among the
evaluated models. Logistic Regression also performed competitively and
provides interpretable feature coefficients.

The Random Forest experiment used a reduced unigram feature space to
manage computational cost, so its result is not a perfectly controlled
comparison with the other models.

## 6. Final Evaluation

The selected models were evaluated on a held-out test set after model
selection and cross-validation.

The evaluation includes:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- ROC curves
- Logistic Regression coefficient analysis
- Learning-curve analysis
- Misclassified-review analysis

The final test metrics and plots are stored in the `results/` directory.

## 7. Error Analysis

A sample of 30 misclassified reviews was inspected.

The observed errors include:

- Sarcasm and irony
- Mixed positive and negative opinions
- Reviews with explicit or controversial content
- Reviews where the plot description dominates the sentiment
- Reviews containing ambiguous or context-dependent language

These errors illustrate the limitations of bag-of-words and TF-IDF
representations, which do not fully capture context, sarcasm, or the
overall meaning of a review.
